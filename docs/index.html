Instalacja w chmurze – jednorazowo

Zajmie ok. 3 minuty. Aplikacja zamieszka na Twoim koncie GitHub (za darmo) i będzie działać bez komputera, a sterować nią będziesz ze strony na telefonie.

1Załóż konto na github.com ↗ (jeśli nie masz) i zaloguj się.
2Utwórz token ↗ – na tej stronie: „Expiration” ustaw na No expiration, zjedź na dół, kliknij Generate token i skopiuj ciąg zaczynający się od ghp_.
3Wklej token poniżej i kliknij „Zainstaluj”.
